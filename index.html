Getting started

  • Plan: tap + to create a practice or match session. Swipe left on a session to delete it.
  • Log: record drills, duration, match scores, and rackets used. Reflections are optional.
  • Skills: view skill cues, notes, and review items.
  • Review: view weekly statistics, recent skill practice, and local rule-based suggestions.
  • Me: manage rackets, strings, partners, courts, and settings.

Choosing a personal or shared calendar

Create or edit a session and tap Calendar. Calendars are grouped by account. The default in Settings applies to new events without an explicit calendar choice.

A shared calendar must first be available in iPhone Calendar, and you must have editing permission. Read-only calendars show a lock and cannot be selected as a destination. If a calendar is missing, use Refresh calendars and check the account and sharing settings in the system Calendar app.

Calendar additions or updates are not working

Check DropShot's calendar permission in iPhone settings and allow full access. This enables calendar selection and management of linked events.

Enable Me → Settings & backup → Automatically add new sessions to add new sessions when saved. Otherwise, add an event manually from session details. Editing a linked session updates its original event. Changes made directly in Calendar are not imported into DropShot.

If a linked event cannot be found, unlink it and add it again manually. Changing the default calendar does not move existing events. To change one event's destination, edit that session and select another calendar.

Deleting sessions and events

When deleting a linked session, choose whether to delete only the app session or also its calendar event. Delete from calendar in session details removes the event while keeping the app's session and records. Turning off automatic addition or deleting the app does not remove existing calendar events.

Backups, moving devices, and restoring

In Me → Settings & backup, choose Export backup (JSON) and save the file. On another device, install DropShot and use Restore from backup on the same settings page.

Restoring replaces current local data. Export anything you want to keep first. Backups can contain partner contact details and private notes, and are not separately encrypted by the app. Store them carefully. DropShot has no account-based cloud sync, and the developer has no record copies to recover for you. Recovery through system device backups depends on your system settings.

How court activity is counted

Each practice or match record linked to a court counts once, even if multiple records are on the same day. Plans, court selections, and navigation do not count. Courts show total sessions, this month's sessions, and the latest session date. Deleting a record or changing its court changes the statistics.

Is location permission required?

No. You can search by court name or address without location permission. Location helps with nearby results and distances. Map searches need an internet connection.

Data, appearance, and language

Training records are primarily stored on your device. Calendar services, maps, exported files, and system backups follow their own settings. See the Privacy Policy.

Appearance follows the system's light or dark mode. Select Chinese, English, or the system language in Settings.

Reporting a problem

Email the support address above with the app version, iOS version, iPhone model, reproduction steps, expected result, and actual result. If useful, include a screenshot with private information hidden. Do not send Apple Account passwords, unrelated calendar contents, or an entire backup with your initial request. We will explain any additional information needed.
